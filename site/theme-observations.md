# Existing theme migration observations

The owner-provided backup was inspected read-only on 2026-10-24. `themes/theblogger/style.css` identifies **TheBlogger 2.3.3**, Pixelwars, ThemeForest License. The commercial source package and PHP files remain outside Git. Local use of this supplied theme for the existing site's customized end product can proceed; see `public/theme/LICENSES.md` for the distinct public source-package redistribution boundary.

The public homepage HTML and backup theme together establish concrete reproduction inputs:

- Responsive styles have tablet and desktop breakpoints at 768px and 992px. The live configuration overrides desktop body size to 19px with line height 1.7, regular archive title size to 32px and metadata to 12px. Sidebar text is 14px and sidebar width is 280px.
- The live header uses the uploaded `2018/07/Pujolsluis-Icon.png` logo, not a text-only title, with alt text `Pujolsluis Blog` and the tagline `Software Engineering & Mobile Development blog`. Live customization specifies a desktop logo maximum height of 54px. The source HTML enables the small header and logo-sticks-with-menu variants; exact resulting geometry needs browser comparison.
- The actual main menu has Home and Activities (`/category/activities/`), with a search control and mobile menu. It is not a menu of every WordPress page. The synthetic fixture menu is scaffolding and must be replaced from the source menu inventory before fidelity acceptance.
- The homepage uses the `blog-stream blog-regular` presentation, right sticky/sidebar alignment, centered post titles and excerpt text, category/date/share/like metadata, featured images and original excerpts. The source contains recent posts/comments and author/badge/media widgets. Copying just article body HTML cannot reproduce these features.
- Karla is used for body/navigation/metadata/widget headings; Coustard for article and content headings and some sidebar links. The current foundation bundles these fonts under OFL. Desktop navigation settings use 12px bold text and 4px letter spacing; widget headings use 12px bold text and 6px spacing. The observed menu active/hover accent is `#338f82` with white text.
- Source DOM settings include sticky menu/sidebar, sidebar title arrows, minimal share/comment styling, rounded category links and post media overflow. These require actual DOM/state reproduction and interaction checks, not guessed static equivalents.

Next integration needs an explicit normalized site-configuration input for logo/menus/sidebar/theme settings, featured-media alt/caption metadata and archived public snapshots. The renderer currently supports contract-driven articles and previews; its original foundation styles are not a claim that this theme has already been faithfully reproduced. Public shop/cart/checkout/account pages and their behavior must be inventoried and resolved separately. Raw WXR and private settings must not be copied into a public artifact.

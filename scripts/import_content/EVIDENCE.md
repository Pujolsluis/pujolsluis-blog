# MIG-02 implementation evidence

This is fixture and private-source audit evidence, not production publication acceptance. It depends on MIG-01 content 1.1.0 and route 1.0.0 contracts. No raw WXR, drafts, private reports, comments' personal data, credentials or full media archives are committed; selected public media files are part of the preview under `static/`.

Run with Python 3.12 and pinned `requirements-dev.txt`:

```sh
python -m unittest discover -s tests/import_content -v
python -m unittest discover -s tests -v
ruff check --no-cache .
```

The fixture suite checks exact rendered HTML, code whitespace, Unicode, GUID, author/taxonomy IDs, local/GMT offsets, excerpts, comments, featured assets, URL paths and fragment IDs. Snapshot hash mismatches, unresolved shortcodes/blocks, unexpected XML/meta/custom records, unsafe comments, duplicate paths/IDs and nonpublic publication attempts fail with source-ID diagnostics. Source duplicate anchors are preserved in HTML and reported privately while route fragments list browser target names once. Tests also cover hash-bound literal brackets, explicit utility/backend deferrals, source-head values/absences/checksums, attachment HTML routes and selected owned media rewriting. Repeat imports are byte-identical. A final full-export delta removes records absent from the replacement export and the Hugo adapter removes stale generated files while protecting owner edits. The private report hashes both `content.json` and `routes.json`; the Hugo report hashes each output file and original/rewritten body.

A read-only audit of the owner's WXR 1.2 export found 550 source items: 45 published posts, 12 published pages, 12 published portfolios, 448 attachments, 11 drafts and 22 published utility/custom records. All 69 public content URLs have hash-bound live source-head records. The publication policy retains 45 posts and two pages while excluding 19 verified theme-demo public records; the three WooCommerce shortcode pages (`/cart/`, `/checkout/`, `/my-account/`) remain explicitly backend-dependent. The 22 utility records are individually classified by source ID, exact URL and type (15 navigation items, four ad configurations, two newsletter forms, one template configuration). The private report also lists 15 image class IDs absent from WXR attachment records, four pages with duplicate source anchors, and all metadata keys whose effects remain unresolved. None of those private values or raw snapshots are committed.

The 98 attachment-like URLs common to the public sitemap and owner WXR are public HTML pages in the observed capture: HTTP 200, unchanged final URL and self canonical. Their full page HTML snapshots remain private. The attachment freezer binds each page to WXR ID/URL and source checksum, then extracts live body/title/caption/image references and body/full-page fragment sets. The publication policy excludes 76 wrappers with exact theme-demo GUID matches and retains 22 other attachment routes. The earlier aggregate media selector total (1,701 of 1,714 owned-reference occurrences) predates those exclusions and is historical; rerun the selector against retained routes before final acceptance. Eighteen selected demo-only output files are removed; two shared brand icons remain.

The captured full attachment shells contain 10,167 source-fragment occurrences across 98 pages (397 distinct IDs), including theme header/footer/sidebar and comment areas. Those source shell fragments are not copied wholesale into the Hugo body; the current layout renders the reviewed body and a site-owned shell. Comments are intentionally omitted: the importer removes captured comment blocks, avatars and comment forms, and adds no comment bridge. Other backend forms are omitted and linked to their original live page in the preview. Per-route source HTML and fragment/link details remain private.

The hash-bound ledger [`migration/theme-demo-exclusions.json`](../../migration/theme-demo-exclusions.json) records the 19 public demo-content and 76 attachment-page exclusions plus 18 demo-only media paths. All 45 authored posts remain, as do the two images shared by demo rendering and authored posts. The Hugo preview contains 69 retained records (45 posts, two pages and 22 attachment routes); portfolio demos and their index are no longer materialized. Comments are excluded by owner decision. MIG-05 still must reconcile archives, feeds, aliases and query routes; MIG-08 must rebind the policy to the final export, recalculate retained media coverage, review image quality and complete the visual walkthrough before launch.

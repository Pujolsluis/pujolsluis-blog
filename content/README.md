# Blog content

The preview content in this repository contains 45 Markdown posts, 8 pages, 13 portfolio entries and 98 attachment pages from the reviewed WordPress export and frozen rendered-page evidence. Every imported blog post is a `.md` file under `posts/`, with JSON front matter preserving its exact public route and source metadata. Text, headings, lists, links, code and common images are editable Markdown; Hugo shortcodes preserve supported figures, galleries, YouTube videos and Gists, while complex source blocks stay as HTML inside the Markdown post. Hugo uses these posts for the home page, archives, search index and RSS feed. Portfolio, page and attachment route files remain HTML under `portfolio/`, `page/` and `attachment/`.

To edit an imported article, create a branch, update its `.md` file and open a pull request against `master`. Preserve its JSON front matter and exact `url` unless the route change has been reviewed. For new posts, use the Markdown workflow in [the editorial guide](../docs/editorial/README.md). Merging a reviewed PR to `master` runs tests and deploys the preview through GitHub Actions.

Comments and comment forms are intentionally not migrated. The imported bodies remove any captured comment threads, avatar markup and WordPress comment submission form. Other WordPress submission forms are omitted from the static preview and replaced with a link to the original live page while WordPress remains production. Three plugin-backed commerce pages and unresolved media/embed references are tracked in the [preview status report](../docs/reports/content-preview.md). The report is aggregate-only; private WXR, comment data, source snapshots and importer reports stay outside Git.

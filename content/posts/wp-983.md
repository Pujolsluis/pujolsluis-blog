Hey Guys!

Recently we had the need for supporting streaming and broadcast playback for one of our App’s, making use of the Wowza Media Services but the only issue was that they were only available on their iOS and Android native SDK’s. Well not anymore!🥳
[XamBoy](<http://www.xamboy.com/>)
 and I got to work and now we have just pre-released a brand new Plugin and set of Xamarin Bindings for the community.

<a id="more-983"></a>

## Set Up

The setup process for the plugin is pretty simple and it’s well documented on the 
[Wowza Client Plugin GitHub page.](<https://github.com/CrossGeeks/WowzaClientPlugin>)
 you can complete the Setup process following these steps:

* Install the <a id="3"></a>

  nuget package into your PCL project and Client projects.

{{< figure src="/pujolsluis-blog/wp-content/uploads/2019/02/Screenshot-Plugin-Wowza-Install.png" class="aligncenter" imgClass="wp-image-1072" width="500" height="344" >}}
{{< /figure >}}

* Create your [Wowza Cloud Console](<https://github.com/CrossGeeks/WowzaClientPlugin/blob/master/WowzaClient/docs/WowzaCloudConsoleSetup.md>) Livestream.
* Follow the [OBS Streaming Software](<https://github.com/CrossGeeks/WowzaClientPlugin/blob/master/WowzaClient/docs/OBSSetup.md>) setup guide.
* Follow the [Getting Started](<https://github.com/CrossGeeks/WowzaClientPlugin/blob/master/WowzaClient/docs/GettingStarted.md>) guide.

**WowzaClient.Current**

Hey Guys!

I recently had the opportunity of participating for the first time at Tampa Code Camp which was hosted on Keiser University this past 26 of October by the Tampa Dev Community, where I had the opportunity of giving a series of talks taking our attendees from Zero to Hero on Mobile Development with Xamarin and all its Goodies ☺️🙌.

Event name:                                    Tampa Code Camp, October 2019

Talk Title:                             Cross-Platform Mobile Development with Xamarin Forms

Description:                                     We got to learn all the fundamentals of Mobile Development and how Xamarin.Forms expose a complete cross-platform UI toolkit for .NET developers. Allowing us to Build fully native Android, iOS, and Universal Windows Platform apps using C# in Visual Studio.

Language:                                        English

Website:                                       https://tampacc.org/

My participation was on the Mobile Development Track, I got to meet the Tampa Community and we learned about Mobile Development with Xamarin all it provides us as .NET Developers, to build fully native Android, iOS and UWP app’s using C# and Visual Studio with a single code base that can share up to 80 – 90% of its code.

I divided my participation in a series of 3 talks, to give the code camp attendees a Zero to Hero overview on Mobile Development and how we are applying it in real-world projects at the moment:

1st Talk (this post): Cross-Platform Mobile Development with Xamarin Forms

2nd Talk: Let’s talk architecture with Prism in Xamarin Forms

3rd Talk: Mobile DevOps Made Easy with VS App Center

I Really enjoyed meeting the Tampa Community and seeing in first hand all the efforts put into the event by the community and all the attendees. I loved the vibe of “By the Community for the Community” which is really in sync with how we also view our events in DotNetDo and the event overall was really well organized. Special thanks to Greg Leonardo and Kate Leonardo for their hospitality and making all of this a reality. 🥳

Also got to meet great speakers, and attendees in my talk all from different backgrounds that love to learn and share their knowledge with others, if you ever have the chance to visit this code camp next year, don’t miss out it’s totally worth it! ☺️🙌

  • A common problem faced by potential mobile development clients
  • What is Xamarin Forms?
    • How does it work?
    • Project structure.
    • Development Environments available
    • Main Components of our Mobile App
      • Pages
      • Layouts
      • Views

    • UI Rendering
  • Live Demo on how to create our first Xamarin Forms App’s.
  • Xamarin Monkey Raffle Winner: Martin 🙈🥳

Just released the 
[LinkedIn Client Plugin](<https://www.nuget.org/packages/Plugin.LinkedInClient/>)
, it makes the process of authenticating a user across Xamarin Forms, Xamarin.Android and Xamarin.iOS with LinkedIn SDK easier.

<a id="more-99"></a>

## ![](</pujolsluis-blog/wp-content/uploads/2018/07/linkedinclient.gif>)

## Set Up

The setup process for the plugin is pretty simple and it’s well documented on the 
[LinkedIn Client Plugin GitHub page](<https://github.com/CrossGeeks/LinkedInClientPlugin>)
. you can complete the Setup process following these steps:

* Install the nugget package into your PCL project and Client projects.

![](</pujolsluis-blog/wp-content/uploads/2018/07/Screen-Shot-2018-07-15-at-1.43.57-PM.png>)

* Create your [LinkedIn Developer Console](<https://github.com/CrossGeeks/LinkedInClientPlugin/blob/master/LinkedInClient/docs/LinkedInDeveloperConsoleSetup.md>) Platform application.
* Follow the [Android](<https://github.com/CrossGeeks/LinkedInClientPlugin/blob/master/LinkedInClient/docs/AndroidSetup.md>) and [iOS](<https://github.com/CrossGeeks/LinkedInClientPlugin/blob/master/LinkedInClient/docs/iOSSetup.md>) guides.

## Use It

You just have to use 
**LinkedInClient.Current**

### Login

Here is an example of how to launch the login to the LinkedIn Client:

```
    CrossLinkedInClient.Current.LoginAsync();
```

This method returns a LinkedInResponse object which contains the basic profile of the user that was authenticated as a string of raw JSON on its Data Property, this response class has the following structure:

![](</pujolsluis-blog/wp-content/uploads/2018/07/Screen-Shot-2018-07-15-at-2.24.46-PM.png>)

### Logout

Here is an example of how to log out of the LinkedIn Client:

```
    CrossLinkedInClient.Current.Logout();
```

### Get Extra Fields from User Profile

You have a public method available that allows you to get extra information you might need from the user profile, just send a list of strings with the fields you require. (
[List of available fields](<https://developer.linkedin.com/docs/fields/basic-profile>)
)

![](</pujolsluis-blog/wp-content/uploads/2018/07/Screen-Shot-2018-07-15-at-2.27.07-PM.png>)

### Available Properties

* **ActiveToken** (Signed In user Token)
* **TokenExpirationDate** (Signed In user Token Expiration Date)

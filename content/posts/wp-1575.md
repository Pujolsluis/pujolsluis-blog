I recently had the opportunity of participating for the first time at 
**Tampa Code Camp**
 which was hosted on 
**Keiser University this past 26 of October**
 by the Tampa Dev Community, where I had the opportunity of giving a series of talks taking our attendees from Zero to Hero on Mobile Development with Xamarin and all its Goodies, on this talk we talked how we could sprinkle some DevOps on our app with the help of Visual Studio App Center🥰.

<a id="more-1575"></a>

**Event name:**
 Tampa Code Camp, October 2019

**Talk Title:**
 Mobile DevOps Made Easy with VS App Center

**Description:**
 We got to learn about DevOps making use of all the great services Visual Studio App Center provides us, to take advantage of all the tools we need to automatically manage our Mobile DevOps.

**Language:**
English

**Website:**
[https://tampacc.org/](<https://tampacc.org/>)

My participation was on the 
**Mobile Development Track**
, I got to meet the Tampa Community and we learned about Mobile Development with Xamarin all it provides us as .NET Developers, to build fully native Android, iOS and UWP app’s using C# and Visual Studio with a single code base that can share up to 80 – 90% of its code.

I divided my participation in a series of 3 talks, to give the code camp attendees a Zero to Hero overview on Mobile Development and how we are applying it in real-world projects at the moment:

[1st Talk:](<https://www.pujolsluis.com/cross-platform-mobile-development-with-xamarin-forms-tampacc/>)
 Cross-Platform Mobile Development with Xamarin Forms

[2nd Talk:](<https://www.pujolsluis.com/lets-talk-architecture-with-prism-tampacc/>)
 Let’s talk architecture with Prism in Xamarin Forms

**3rd Talk (this post):**
Mobile DevOps Made Easy with VS App Center

On our last talk of the day, we got to see how many tedious and manual processes we are actually doing daily as developers, and how we can use DevOps to automate them using the awesome services provided by Visual Studio App Center and how it also provides us a bunch of other goodies that allow us to have more power in our app like Crashanalitics, Analytics, Events, Push Notifications, etc.

#### **TOPICS DISCUSSED ON THE LIVE PRESENTATION**

* What is DevOps?
* DevOps applied to Mobile Development
* Visual Studio App Center
  * Build
  * Testing
  * Distribute
  * App Health and CrashAnalytics
  * Analytics and User Behavior
  * Push Notifications
  * Pricing? Free for Devs! 🥳
* Live Demo

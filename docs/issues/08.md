# MIG-08: Integrate full archive and prove fidelity in Pages staging

## Prerequisites
02–07 completed; full private source access required.

## Ownership boundary
`migration/reports/, docs/release/`. Work on a dedicated `codex/mig-08` branch/worktree. Do not edit another task's owned files without coordinating. Integrate schema changes through MIG-01 and renderer command changes through MIG-04.

## Work
Run full import, media mapping, rendering and compatibility suites. Compare every published page against frozen source at agreed viewports. Freeze fonts/browser and mask only documented nondeterministic pixels; manually verify masked widgets. Reconcile content/image-use counts and source/output hashes; review the optimized images at actual display sizes and confirm the selected assets plus generated variants meet repository and Pages budgets. Smoke-test staging, validate search/video/forms and rehearse editorial work. Confirm every required legacy media path from the manifest; report excluded WordPress variants and their dispositions. Keep commerce and backend-feature outcomes tied to owner decisions.

## Inputs and outputs
Consume the versioned contracts and sanitized fixtures from MIG-01 (MIG-01 creates these). Produce implementation, tests and an evidence report within the ownership boundary. Use fixtures to work independently of production data; never invent production content.

## Acceptance criteria
- [ ] Zero missing items/assets/routes, zero unexplained content or visual differences, zero unaccepted behavior differences. Reports include denominators and per-item outcomes; no percentage claim based only on samples. Owner reviews actual staging site.
- [ ] Document inputs, outputs, errors and reproducible verification in the PR.
- [ ] Include evidence against every acceptance criterion and identify remaining blockers.

## Verification contract
Implement and run `npm run verify:migration` as part of this task. These future commands are acceptance contracts, not commands available in the initial planning scaffold. MIG-07 wires the completed suites into CI; coordinate shared package scripts with MIG-04.

## Handoff
Link the PR and evidence here. Consumers use the committed contracts/artifacts, not another agent's uncommitted working tree. Do not change production DNS as part of any task other than approved MIG-09.

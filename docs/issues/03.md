# MIG-03: Archive original media and implement asset mapping

## Prerequisites
01 asset contract; fixture development can run alongside 02.

## Ownership boundary
`scripts/import_media/, public/wp-content/, tests/import_media/, migration/assets/`. Work on a dedicated `codex/mig-03` branch/worktree. Do not edit another task's owned files without coordinating. Integrate schema changes through MIG-01 and renderer command changes through MIG-04.

## Work
Copy owned originals and required derivatives byte-for-byte. Record source URL, destination, MIME, bytes, SHA-256, dimensions and references. Cover srcset, CSS backgrounds, posters, captions, audio, video and downloads. Preserve embed provider IDs, parameters, aspect ratios and captions. Detect old-host/CDN dependencies. Do not transcode or silently drop assets to fit limits.

## Inputs and outputs
Consume the versioned contracts and sanitized fixtures from MIG-01 (MIG-01 creates these). Produce implementation, tests and an evidence report within the ownership boundary. Use fixtures to work independently of production data; never invent production content.

## Acceptance criteria
- [ ] All owned assets have verified hashes; no unresolved references; embedded players pass playback checks. If limits require external owned storage, document a decision and get owner agreement before architecture changes.
- [ ] Document inputs, outputs, errors and reproducible verification in the PR.
- [ ] Include evidence against every acceptance criterion and identify remaining blockers.

## Verification contract
Implement and run `python -m unittest discover -s tests/import_media -v` as part of this task. These future commands are acceptance contracts, not commands available in the initial planning scaffold. MIG-07 wires the completed suites into CI; coordinate shared package scripts with MIG-04.

## Handoff
Link the PR and evidence here. Consumers use the committed contracts/artifacts, not another agent's uncommitted working tree. Do not change production DNS as part of any task other than approved MIG-09.

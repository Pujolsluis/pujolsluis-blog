# MIG-09: Rehearse and execute reversible domain cutover

## Prerequisites
08 fidelity gate passed; explicit owner approval required before DNS/custom-domain changes.

## Ownership boundary
`docs/operations/, migration/release/`. Work on a dedicated `codex/mig-09` branch/worktree. Do not edit another task's owned files without coordinating. Integrate schema changes through MIG-01 and renderer command changes through MIG-04.

## Work
Record current DNS and WordPress restore path. Lower TTL in advance, freeze edits briefly, run final delta import, rerun fidelity gates. Verify domain ownership, configure canonical www domain and apex handling, deploy production root with correct canonical URLs/sitemap/indexability, update only web DNS and enable HTTPS. Preserve MX/TXT mail records. Retain WordPress for rollback.

## Inputs and outputs
Consume the versioned contracts and sanitized fixtures from MIG-01 (MIG-01 creates these). Produce implementation, tests and an evidence report within the ownership boundary. Use fixtures to work independently of production data; never invent production content.

## Acceptance criteria
- [ ] Record approved launch, both hostnames and HTTPS work, all legacy URLs/media pass post-launch smoke tests. Roll back DNS and prior artifact on content loss, certificate failure or critical feature failure. Keep origin available for at least 14 days and until owner accepts shutdown.
- [ ] Document inputs, outputs, errors and reproducible verification in the PR.
- [ ] Include evidence against every acceptance criterion and identify remaining blockers.

## Verification contract
Implement and run `npm run verify:production` as part of this task. These future commands are acceptance contracts, not commands available in the initial planning scaffold. MIG-07 wires the completed suites into CI; coordinate shared package scripts with MIG-04.

## Handoff
Link the PR and evidence here. Consumers use the committed contracts/artifacts, not another agent's uncommitted working tree. Do not change production DNS as part of any task other than approved MIG-09.

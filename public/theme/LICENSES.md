# Renderer asset provenance

`renderer.css` is original code for this migration foundation. It implements structural observations from the public homepage; it does not contain copied TheBlogger CSS, JavaScript, fonts, logos, photos or icon files. The owner-provided backup identifies TheBlogger 2.3.3 by Pixelwars and declares the ThemeForest License. The backup remains private and unchanged.

The [official Regular License](https://themeforest.net/licenses/terms/regular) permits a customized single end product and modifications (clauses 2, 3 and 6). Clause 8 restricts redistribution of the item as a reusable template or source package. These are distinct from local use of the supplied theme to migrate this existing site. The migration may inspect/use it locally and produce necessary frontend assets for the same customized end product; this foundation does not publish the raw PHP/theme package. The exact purchased license and third-party asset licenses should be retained with the owner before the final public artifact is packaged. No inferred lack of standalone redistribution permission blocks legitimate local theme inspection/reproduction.

The observed homepage requested Karla and Coustard through Google Fonts. This build uses locally bundled **@fontsource/karla 5.3.0** and **@fontsource/coustard 5.3.0**, both distributed under **SIL Open Font License 1.1**. Their original `LICENSE` texts are retained here as `Karla-OFL.txt` and `Coustard-OFL.txt`; font files are bundled by Astro from the locked packages. No browser request to Google Fonts or the WordPress theme server is needed. Latin/Latin Extended Karla regular/italic/bold and Latin Coustard regular are included; other scripts use system fallbacks until the source baseline establishes requirements.

Package sources: [Karla](https://www.npmjs.com/package/@fontsource/karla), [Coustard](https://www.npmjs.com/package/@fontsource/coustard). Astro and parse5 use MIT licenses; Ajv and ajv-formats use MIT licenses. Exact package versions and transitive dependencies are recorded in the root lockfile.

`fixtures/v1/media/example.svg` is the synthetic MIG-01 fixture, verified and copied to the output with its original bytes. No production media is included by this renderer work.
